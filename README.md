## Selected work

### Constructo — a home for a creator's work

Developers and creators need a place to bring their projects, links and online profiles together. I built a customizable profile-page SaaS with a drag-and-drop editor and GitHub and Discord integrations.

I implemented paid plans with **AbacatePay and webhooks**, alongside authentication, storage and page analytics.

**Built with** TypeScript, Next.js, Supabase and PostgreSQL.

[Visit Constructo](https://constructo.lol)

### Clakete — keep and share your movie history

I built a social movie diary for tracking films and series, writing reviews and sharing lists. Letterboxd imports let people bring their existing history with them.

I maintain the web app, live since 2025, with a TMDB-powered catalog, authentication and PostgreSQL storage. A native iOS app in SwiftUI is in development.

**Built with** TypeScript, Next.js, Supabase and the TMDB API.

[Open Clakete](https://www.clakete.xyz) · [Explore the code](https://github.com/MAUXII/clakete)

### Gazette — your morning briefing, delivered as a newspaper

Weather, news, repository activity and calendar events live in separate places. I built a Python agent that collects those sources, writes an edition and renders it as a newspaper image for delivery by message.

The pipeline separates data collection, model-generated writing and image rendering. It runs on Hermes in Docker, with scheduled execution and an optional calendar connection.

**Built with** Python, Hermes, Pillow and Docker.

[Explore the code and sample editions](https://github.com/MAUXII/gazette)
