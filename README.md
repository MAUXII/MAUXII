## Selected projects

### Constructo · Profile pages for developers and creators

Projects, links and social profiles are often scattered across platforms. Constructo brings them together in a customizable page, with a drag-and-drop editor and GitHub and Discord integrations.

I implemented authentication, storage, page analytics and paid plans using AbacatePay and webhooks.

**TypeScript · Next.js · Supabase · PostgreSQL · AbacatePay**

[Visit Constructo](https://constructo.lol)

### Clakete · A shared movie diary

Clakete gives people a place to track films and series, write reviews and share lists. Letterboxd imports let them bring their existing viewing history.

I maintain the web application, live since 2025, with a TMDB-powered catalog, authentication and PostgreSQL storage.

**TypeScript · Next.js · Supabase · TMDB**

[Open Clakete](https://www.clakete.xyz) · [Read the code](https://github.com/MAUXII/clakete)

### Gazette · A morning briefing in newspaper form

News, weather, repository activity and calendar events live in separate places. Gazette collects these sources and turns them into an illustrated newspaper delivered by message.

The Python pipeline separates data collection, model-generated writing and image rendering, with scheduled execution in Docker and an optional calendar connection.

**Python · Hermes · Pillow · Docker**

[Code and sample editions](https://github.com/MAUXII/gazette)
